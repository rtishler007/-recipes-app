# המתכונים שלי

אפליקציית מתכונים אישית שרצה על Google Apps Script ושומרת את המתכונים בגיליון Google Sheets.

- **צ'אט** — מבקשים מתכון מ-Claude, ממשיכים לדייק אותו בשיחה, ולוחצים "שמור".
- **המתכונים שלי** — רשימה, חיפוש, פתיחה, עריכת פרטים, "שפר בצ'אט" ומחיקה. כל מתכון הוא שורה בגיליון.
- **משימות** — כל שלב הוא משימה עם תיבת סימון, וטיימר לשלבים שיש בהם זמן המתנה (אפייה, התפחה וכו').
- **מטריצה** — טבלת מתכון בסגנון Cooking for Engineers: המצרכים בעמודה הימנית, והפעולות משמאל להם.

---

## מה צריך לפני שמתחילים

1. **חשבון Google** — אותו חשבון שבו נמצא הגיליון.
2. **מפתח API של Anthropic** — מנוי Claude.ai רגיל **לא** כולל גישה ל-API. זה חשבון נפרד עם תשלום מראש:
   1. היכנס ל-<https://platform.claude.com> והירשם (אפשר עם אותו מייל).
   2. בתפריט **Billing** הוסף אמצעי תשלום וקנה קרדיט. הסכום המינימלי קטן, וקרדיט של כמה דולרים מספיק להרבה מתכונים.
   3. מומלץ: ב-**Settings ← Limits** הגדר תקרת הוצאה חודשית, כדי שלא תהיה הפתעה.
   4. ב-**API Keys** לחץ **Create Key**, תן לו שם (למשל "recipes") והעתק אותו. המפתח מוצג **פעם אחת בלבד**. הוא מתחיל ב-`sk-ant-`.
   5. אל תשלח את המפתח לאף אחד ואל תדביק אותו בקוד או בצ'אט. המקום היחיד שלו הוא Script Properties (שלב 4 בהמשך).

**עלות משוערת:** כמה סנטים להודעה בצ'אט. שיחה ארוכה עולה יותר, כי כל ההיסטוריה נשלחת מחדש בכל הודעה.

## התקנה — צעד אחר צעד

### שלב 1: פתיחת פרויקט Apps Script

1. פתח את הגיליון ב-Google Sheets.
2. בתפריט העליון: **הרחבות (Extensions) ← Apps Script**.
3. ייפתח עורך עם קובץ בשם `Code.gs`. למעלה, לחץ על "Untitled project" ותן לפרויקט שם, למשל "המתכונים שלי".

### שלב 2: העתקת הקבצים

בפרויקט צריכים להיות חמישה קבצים. את התוכן של כל קובץ מעתיקים מהרפוזיטורי ב-GitHub: פותחים את הקובץ, לוחצים על כפתור ההעתקה (Copy raw file) ומדביקים בעורך.

| קובץ ברפוזיטורי | מה עושים ב-Apps Script |
|---|---|
| `Code.gs` | מוחקים את כל מה שיש בקובץ `Code.gs` הקיים ומדביקים במקומו |
| `index.html` | לוחצים **+** ליד "Files" ← **HTML**, קוראים לו `index` (בלי ‎.html) ומדביקים |
| `styles.html` | **+** ← **HTML**, השם: `styles` |
| `app.html` | **+** ← **HTML**, השם: `app` |
| `appsscript.json` | ראו בהמשך |

**הקובץ `appsscript.json`** מוסתר כברירת מחדל:
1. לחץ על ⚙️ **Project Settings** (בסרגל השמאלי).
2. סמן ✔ **Show "appsscript.json" manifest file in editor**.
3. חזור ל-**Editor** (סמל `< >`), פתח את `appsscript.json`, מחק את התוכן והדבק את התוכן מהרפוזיטורי.

לחץ 💾 **Save** (או Ctrl+S).

> השמות חייבים להיות בדיוק `index`, `styles` ו-`app`. הקוד מחפש אותם לפי השם.

### שלב 3: הכנסת מפתח ה-API

1. ⚙️ **Project Settings** ← גלול למטה ל-**Script Properties** ← **Add script property**.
2. **Property:** `ANTHROPIC_API_KEY`
3. **Value:** המפתח שהעתקת (מתחיל ב-`sk-ant-`).
4. **Save script properties**.

המפתח נשמר בשרתים של Google ונקרא רק בקוד השרת (`Code.gs`). הוא לא מגיע לדפדפן.

### שלב 4: בדיקה שהכל מחובר

1. ב-Editor, פתח את `Code.gs`.
2. בסרגל העליון, בתפריט שליד **Run**, בחר את הפונקציה `testSetup`.
3. לחץ **Run**.
4. בפעם הראשונה Google יבקש הרשאות:
   - **Review permissions** ← בחר את החשבון שלך.
   - תופיע אזהרה "Google hasn't verified this app". זה תקין, כי זה סקריפט שלך. לחץ **Advanced** ← **Go to ... (unsafe)** ← **Allow**.
   - ההרשאות שמתבקשות: גישה לגיליונות (כדי לשמור מתכונים) וחיבור לשירות חיצוני (כדי לדבר עם Claude).
5. ב-**Execution log** בתחתית אמורות להופיע שורות עם ✔: הגיליון נמצא, Claude ענה, והתקבל מתכון לדוגמה (הוא לא נשמר). הבדיקה לוקחת כ-10–30 שניות ועולה סנטים בודדים.

אם יש שגיאה, ראו "פתרון תקלות" בהמשך.

### שלב 5: פרסום האפליקציה

1. למעלה מימין: **Deploy ← New deployment**.
2. ליד "Select type" לחץ ⚙️ ← **Web app**.
3. מלא:
   - **Description:** למשל "גרסה 1"
   - **Execute as:** **Me**
   - **Who has access:** **Only myself**
4. **Deploy**. העתק את ה-**Web app URL** (מסתיים ב-`/exec`).

> **חשוב:** השאר את "Only myself". אם תבחר "Anyone", כל מי שיקבל את הקישור יוכל להשתמש במפתח שלך על חשבונך.

### שלב 6: פתיחה בטלפון

1. פתח את הקישור בדפדפן בטלפון. צריך להיות מחובר שם לאותו חשבון Google.
2. מומלץ להוסיף אותו למסך הבית:
   - **אייפון (Safari):** כפתור השיתוף ← **הוסף למסך הבית**.
   - **אנדרואיד (Chrome):** ⋮ ← **הוסף למסך הבית**.

## עדכון הקוד בעתיד

אחרי שינוי בקבצים, **הקישור ממשיך להציג את הגרסה הישנה** עד שמפרסמים גרסה חדשה:

1. **Deploy ← Manage deployments**.
2. לחץ ✏️ (עריכה) ליד הפריסה הקיימת.
3. ב-**Version** בחר **New version** ← **Deploy**.

הקישור נשאר אותו קישור.

## איך זה עובד (בקצרה)

| קובץ | תפקיד |
|---|---|
| `Code.gs` | צד השרת: מציג את הדף, שולח בקשות ל-Claude, קורא וכותב לגיליון |
| `index.html` | מבנה הדף |
| `styles.html` | העיצוב (עברית, מימין לשמאל, מותאם לטלפון) |
| `app.html` | מה שקורה בדפדפן: צ'אט, רשימה, משימות, מטריצה |
| `appsscript.json` | הגדרות: אזור זמן, הרשאות, ומי יכול לגשת |

**המודל:** `claude-sonnet-5-5` (Claude Sonnet 5.5). מוגדר בראש `Code.gs`.

**מבנה המתכון:** Claude מחזיר כל מתכון כ-JSON:

```
ingredients: [{ id, amount, name }]
steps:       [{ id, title, text, inputs, activeMinutes, waitMinutes }]
```

- `inputs` של שלב הם המזהים של המצרכים ושל השלבים הקודמים שהוא משלב. מהם נבנות גם תצוגת המשימות וגם המטריצה.
- `activeMinutes` הוא זמן עבודה, ו-`waitMinutes` הוא זמן המתנה. טיימר מוצג רק לשלבים עם המתנה.
- כדי שהמטריצה תעבוד, המתכון צריך להיות בנוי כמו עץ: כל מצרך נכנס לשלב אחד, כל שלב נכנס לשלב אחד, והכל מתנקז לשלב האחרון. השרת בודק את זה, ואם יש בעיה הוא מבקש מ-Claude לתקן פעם אחת אוטומטית.
- שלבי הכנה בלי מצרכים (למשל "לחמם תנור") מוצגים מעל המטריצה, תחת "לפני שמתחילים".

**הגיליון:** ה-JSON המלא נשמר בעמודה K, ושאר העמודות מקבלות טקסט קריא.

> **אל תערוך מתכונים ישירות בגיליון.** האפליקציה קוראת רק את עמודה K, ולכן שינוי ידני בעמודות אחרות לא יופיע בה. עורכים דרך האפליקציה: "ערוך פרטים" לשם, קטגוריה, מנות, זמן ותיאור, ו"שפר בצ'אט" למצרכים ולשלבים.

**סימוני "בוצע" והטיימרים** נשמרים רק במכשיר שעליו סימנת, ולא בגיליון.

## פתרון תקלות

| מה רואים | מה לעשות |
|---|---|
| "חסר מפתח API" | לא הוגדר `ANTHROPIC_API_KEY` ב-Script Properties, או שיש טעות בשם (שלב 3) |
| "מפתח ה-API לא תקין" | המפתח הועתק חלקית או נמחק בקונסולה. צור מפתח חדש והחלף |
| "אין מספיק קרדיט" | הוסף קרדיט ב-**Billing** בקונסולה של Anthropic |
| "לא נמצאה לשונית בשם recipes" | שם הלשונית בגיליון חייב להיות בדיוק `recipes` |
| השינויים בקוד לא מופיעים | צריך לפרסם גרסה חדשה (ראו "עדכון הקוד בעתיד") |
| "Sorry, unable to open the file at this time" | קורה כשמחוברים בדפדפן לכמה חשבונות Google. פתח את הקישור בחלון גלישה בסתר עם החשבון הנכון בלבד |
| הצ'אט "חושב" הרבה זמן | תשובה לוקחת בדרך כלל 10–30 שניות. אם מופיעה שגיאת זמן, שלח שוב |
| המטריצה לא מוצגת | פתח את המתכון ב"שפר בצ'אט" וכתוב "תקן את מבנה המתכון". תצוגת המשימות עובדת גם בלי המטריצה |

שגיאות מפורטות אפשר לראות ב-Apps Script תחת **Executions** (בסרגל השמאלי).
